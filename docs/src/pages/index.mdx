# Captain documentation

Captain runs prompts across API and local agent runtimes, records sessions, brokers approvals, and verifies generated work. Start with configuration, preview a prompt, then execute it through the CLI or workbench. Gavel embeds the same runtime for its TODO lifecycle.

```sh
captain configure
captain prompt list
captain prompt render proposal-review -V 'files:=["proposal.md"]' --json
captain prompt run proposal-review -V 'files:=["proposal.md"]'
captain serve --open
```
