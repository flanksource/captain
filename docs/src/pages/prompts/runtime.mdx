# Runtime overlay

The prompt file provides the base request, but it is not the last word. Captain resolves the final runtime request by layering command flags, saved defaults, and workbench edits over the rendered prompt.

<RuntimeSpecDemo client:only="react" />

## Precedence

<div className="docs-step">
  <h3>1. Prompt frontmatter</h3>
  <p>The `.prompt` file declares the base model, budget, permissions, memory, setup, and prompt metadata.</p>
</div>
<div className="docs-step">
  <h3>2. Saved defaults</h3>
  <p>`captain configure` values fill gaps such as default model, backend, max tokens, budget, no-cache, and memory toggles.</p>
</div>
<div className="docs-step">
  <h3>3. CLI or UI overlay</h3>
  <p>Explicit runtime choices override the base file and defaults. Negative toggles such as no-MCP and no-hooks stay enabled once set by any layer.</p>
</div>
<div className="docs-step">
  <h3>4. Context normalization</h3>
  <p>The prompt command resolves an empty workspace directory to the invocation cwd and resolves relative directories from that same cwd before provider dispatch.</p>
</div>

## Model and backend

The prompt workbench keeps runtime selection catalog-backed. The UI groups by provider family first, then mode/backend, then the model list filtered to that backend. Prompt files can still name `model` and `backend` directly when the runtime should be pinned.

## Parallel runtimes

A prompt can declare its default comparison matrix at the root. Running the file without `-M` dispatches all declared runtimes concurrently, and the workbench opens them as editable runtime rows. Each entry accepts the compact model selector or object form, and a matrix must contain at least two distinct runtimes.

<CodeExample client:load language="yaml" title="Prompt-owned runtime matrix" source={`
---
name: Compare screenshot audits
runtimes:
  - api:gemini-3.5-flash:high
  - model: claude-sonnet-5
    backend: anthropic
    effort: medium
---
{{role "user"}}
Review the attached screenshot.
`} />

The matrix supplies defaults rather than locking the prompt. Explicit CLI `-M` selectors or HTTP/workbench `runtimes` replace the declared list for that run. A singular `model` is optional when the prompt declares a runtime matrix.
