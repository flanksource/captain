# pkg/substrate

A client for [agent-substrate](https://github.com/agent-substrate/substrate) environments, served
by [agent-substrate/env](https://github.com/agent-substrate/env)'s ate-env-api.

`Dial(Options)` connects to ate-env-api and to ate-api-server (the control plane, which egress
policies are set through). From another cluster, both sit behind an ingress that requires a client
certificate (`ClientCertFile`/`ClientKeyFile`). The certificate is read on every handshake and
`ControlTokenFile` on every call, so renewed ones are used without reconnecting.

`Client.Create(Environment)` creates an environment from `Options.Template`, which sets the image it
runs, and sets its actor's egress policy. An environment whose policy can't be set
is deleted. Everything the policy doesn't name is denied:

- `Egress.Passthrough`: hosts reached over TLS, passed through undecrypted;
- `Egress.HTTP`: hosts reached in cleartext;
- `Egress.Credentials`: hosts reached over HTTPS, where the egress gateway replaces a header with
  the credential a URI names (`ate-secret://…`), which the cluster's credential provider
  resolves. The key never enters the environment. A process gets `Placeholder` in the
  credential's `Env` variable instead, and the gateway's CA in `NODE_EXTRA_CA_CERTS` when
  `Options.TrustBundle` names where the template mounts it. `CredentialFor(provider, auth)` gives
  the host, header and variable of the keys captain knows.

An `Env` moves files in and out (`WriteFile`, `ReadFile`, both streamed) and starts processes
(`Start`). A `Proc` follows its output, interleaved (`Output`) or one stream at a time (`Stdout`,
`Stderr`), reconnecting from its offsets when Substrate's router ends the stream. It writes to the
stdin of a process started with `Stdin` (`Input`, one call per write, so an ended stream loses
nothing). It waits for its exit code (`Wait`) and kills its process group (`Kill`). `Delete` deletes the environment.

`Client.ListActors(atespace)` lists the actors of an atespace, or of every atespace when it is
empty, with their state and create time. `Client.ListWorkers()` lists the workers they run on, with
each one's pool, node, state, and capacity and allocation (CPU, memory and actor slots). `Sweep`
deletes the environments a dead caller left behind, from the atespace's actor list.

## Generated API

`internal/ateapi`, `internal/credprovider` and `internal/ateenvv1alpha` are generated by `go
generate` from Substrate's and env's protos, fetched by buf from the tag or commit each package's
`buf.gen.yaml` pins. To follow a Substrate or env release, bump the pin and run `go generate
./pkg/substrate/...`. Generating them here, rather than importing Substrate's and env's packages,
keeps their Go modules and the Kubernetes version they bring out of captain's.

`RegisterCredentialProvider(server, fetch)` serves Substrate's CredentialProvider API, which the
egress gateway asks for the credential an `ate-secret://` URI names, from `fetch`.
`substratetest.FetchSecret` asks one as the gateway does.

## Tests

`substratetest.Start` serves both APIs in-process. Each environment is a temp directory, and its
processes are real processes run in it, so the client's tests run real commands on real files.

`TestAnEnvironmentAgainstACluster` runs against a live cluster when `CAPTAIN_SUBSTRATE_TEST=1`. It
uses a kind cluster with Substrate and env installed, as gavel's `docs/sandbox.md` sets one up,
with ate-env-api port-forwarded to `localhost:7777` and ate-api-server to `localhost:8443`. Set
`CAPTAIN_SUBSTRATE_TOKEN_FILE` to a token for the control plane. `CAPTAIN_SUBSTRATE_TEMPLATE`
(default `default-template`) names the template environments are created from, whose image must
have `sh` and coreutils. `CAPTAIN_SUBSTRATE_ENV_API` and `CAPTAIN_SUBSTRATE_CONTROL` override the
rest. For a Substrate behind a client-certificate ingress, set
`CAPTAIN_SUBSTRATE_CLIENT_CERT` and `CAPTAIN_SUBSTRATE_CLIENT_KEY`, and `CAPTAIN_SUBSTRATE_CA_FILE`
when its certificate isn't signed by a system root. `CAPTAIN_SUBSTRATE_ATESPACE` overrides
`ate-env`.

`TestLargeFilesRoundTripAgainstACluster` moves a 50 MiB file in and back out, comparing checksums
on both sides, so a proxy that buffers or cuts gRPC streams shows.
